# 🏡 四年级学习小屋

一个给 10 岁孩子自己用的浏览器学习工具。**不用安装、不用注册**，手机和电脑都能打开。
语文 / 数学 / 英语三个模块，全部用本地模拟数据跑通，教材内容用独立配置文件管理。

## 怎么打开

**最简单**：双击 `index.html` 就能用（Chrome / Edge / Safari 均可）。

**手机上用**（推荐，这样照片能存得更多）：
在本文件夹里开一个终端，执行

```bash
python -m http.server 8000
```

然后手机连同一个 WiFi，浏览器打开 `http://电脑的IP:8000`。

## 三个模块怎么用（每一步都不超过两步）

| 模块 | 入口 | 孩子要做的 |
|---|---|---|
| 📖 语文 | 首页 → 语文 → 选册 → 选单元 → 选课文 | ① 看原文 ②点「🎧 听朗读」进入朗读页：**一页一图一句**，读到哪句画面上就是哪句，字还会跟着念 |
| ✍️ 优秀作文 | 首页 → 语文 → 选册 → 选单元 | 每个单元底部都有「✍️ 3 篇优秀作文」，点进去可读范文，带作者、字数、写法亮点和读后练习 |
| 🔢 数学 | 首页 → 数学 → 拍照/选图 | ① 拍一张错题 ②自动识别知识点、生成 5 道同类题 → 做完自动判分+解析；照片自动进「我的错题本」 |
| 🔤 英语 | 首页 → 英语 → 选册 → 选模块 | ① 选游戏 ②点字母拼单词；听音拼写 / 乱序拼词 / 限时闯关，带积分、等级和鼓励动画。**所有单词、每道题、每次结算都能点 🔊 听发音** |

### 0. 换成本班学生的优秀作文
打开 `data/essay-data.js`，按「册id-单元id」找到对应单元，直接替换那一篇即可：

```js
'4a-u1': [
  {
    title: '我们班的小花园',
    author: '四（3）班 李明',
    words: 400,
    tags: ['按时间顺序', '五感描写'],     // 会显示成小标签
    text: `第一段……\n第二段……\n第三段……`   // 用 \n 分段
  },
  // …这里再放两篇，保持每单元 3 篇
]
```

想加单元：键名照 `<册id>-<单元id>` 写（如 `'4a-u9'`）即可，但单元目录里要有对应的 `u9` 才不会显示；改课文目录在 `data/chinese-data.js`。

### 1. 朗读怎么工作（默认就有声音，不用配任何东西）
点「听朗读」会进入**朗读页**：

- 一页 = 一张图 + 一句话，**声音一句一句读**，读到哪句屏幕就显示哪句；
- 底部可以「上一句 / 下一句」手动翻，点画面任意位置可以从这句开始读；
- 电脑、平板、安卓手机：打开就自动开始读；
- iPhone / 微信里浏览器限制语音必须由用户点击触发，会提示点「▶ 开始朗读」，点一下即可。

**想换成真人朗读视频？** 打开 `data/config.js`，往 `CN_LINKS` 里加一行，键名是「册-课号」：

```js
CN_LINKS: {
  // ① 最省事：直接写视频 ID（19 位数字）
  '4a-1': '7357934509125389631',
  // ② 写完整 PC 端链接，程序自动提取 ID
  '4a-2': 'https://www.douyin.com/video/7357934509125389631',
  // ③ 写对象，还能加提示文字
  '4a-9': { vid: '7357934509125389631', tip: '央视朗读版' }
}
```

**视频 ID 怎么拿？**
把抖音分享链接粘贴到**电脑浏览器**打开，地址栏里 `https://www.douyin.com/video/` 后面那一长串数字就是。
（手机端的短链 `v.douyin.com/xxx` 里没有数字 ID，无法内嵌，必须先在电脑上打开一次。）

内嵌用的是抖音开放平台官方组件 `https://open.douyin.com/player/video?vid=...`，公开视频**无需登录**即可播放。

> 想让朗读内容更长：`data/chinese-data.js` 里现代文目前是精彩片段，补全后朗读会自动变长。

### 2. 补课文全文
`data/chinese-data.js` 里，古诗和小古文已经是全文；现代文因为版权原因只放了**精彩片段**（页面底部会标注）。
把同一课的 `text` 换成完整原文、并把 `full` 改成 `true` 即可，不用改任何代码。

### 3. 换 / 加英语单词
直接编辑 `data/english-data.js` 的 `words` 数组（现在是外研版三起四上、四下 M1–M10 的教材词表）。

### 4. 加数学知识点
在 `data/math-data.js` 的 `MATH_KP` 数组里照抄一条：

```js
{ id:'myid', name:'知识点名', book:'4a', emoji:'🔢', color:'#FF8A3D',
  keywords:['关键词1','关键词2'],     // 用来从 OCR 文字里自动匹配
  gen(){ return { q:'题干（　　）', a:'答案', unit:'单位', exp:'解析文字' } } }
```

`gen()` 里用不同的随机数，每次调用就是一道新的同类题。

## 接真实 OCR（可选）

现在是**本地模拟识别**（离线可用）。要接阿里云 / 百度 OCR：

1. 把 `data/config.js` 里的 `MATH_OCR` 改成 `true`；
2. 在 `js/math.js` 的 `recognizeImage(file)` 里换成你的接口请求，返回
   `{ text: '识别出来的题目文字', kp: '知识点id' }`。

`guessKp()` 会自动按关键词匹配知识点，所以**只要返回文字就够**，不必在接口里做分类。

## 数据存在哪里

全部存在浏览器本地存储里（`localStorage`），**不会上传到任何服务器**：

- 错题照片：自动压缩到最长边 800px 后以 DataURL 存本地，最多保留 60 张；
- 星星积分、上次读到的课文：本地保存，换浏览器会重置。

清除方法：浏览器设置里清该站点的站点数据。

## 已知边界

- 现代文课文为节选片段（见上第 2 条）；
- 抖音链接默认走搜索页，推荐对外开放前把常用课文的真链接录进 `CN_LINKS`；
- 英文朗读用的是系统语音合成（Web Speech API），iOS Safari / Edge / Chrome 均支持，个别安卓机型需要先在浏览器里点一次页面才会出声（浏览器限制）。
